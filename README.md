# portscan

Небольшой Go-пакет для проверки TCP-портов методом TCP Connect. Поддерживает IPv4, IPv6 и DNS-имена, ограничивает число одновременных подключений и возвращает результаты потоком.

Успешное соединение сразу закрывается. Пакет не реализует UDP-сканирование, CLI или хранение результатов. Внешних зависимостей нет.

## Требования и импорт

- Go 1.25.5 или новее (см. `go.mod`).
- Путь модуля: `portscanner`; имя пакета: `portscan`.

```go
import portscan "portscanner"
```

## Структура проекта

| Файл | Ответственность |
|---|---|
| `scanner.go` | Публичные типы, настройки сканера, проверка аргументов и координация сканирования |
| `ports.go` | Наборы портов и их конструкторы |
| `targets.go` | Проверка и дедупликация целей, DNS-разрешение |
| `worker.go` | TCP-подключение и классификация сетевых ошибок |
| `*_test.go` | Тесты API, целей, конструкторов портов и воркеров |

Вся реализация находится в одном пакете `portscan`; внутренние типы и функции не экспортируются.

## Использование

```go
package main

import (
	"context"
	"fmt"
	"time"

	portscan "portscanner"
)

func scan(ctx context.Context) error {
	scanner, err := portscan.New(
		portscan.WithConcurrency(100),
		portscan.WithConnectTimeout(500*time.Millisecond),
	)
	if err != nil {
		return err
	}

	ports, err := portscan.Range(1, 1024)
	if err != nil {
		return err
	}
	results, err := scanner.Scan(ctx, []string{"192.168.1.10", "example.org"}, ports)
	if err != nil {
		return err
	}

	for result := range results {
		fmt.Printf("%s (%v):%d %s\n", result.Host, result.IP, result.Port, result.State)
	}
	return nil
}
```

`Scan` возвращает ошибку сразу, если контекст, цели или набор портов некорректны. Ошибки DNS и подключения приходят как `Result`.

## API

| API | Назначение |
|---|---|
| `New(options ...Option)` | Создаёт потокобезопасный сканер. Значения по умолчанию: 100 одновременных подключений и таймаут 500 мс. |
| `WithConcurrency(n)` | Задаёт положительный лимит параллельных подключений. |
| `WithConnectTimeout(d)` | Задаёт положительный таймаут одной попытки подключения. |
| `Ports(ports ...int)` | Создаёт набор портов `1..65535`; удаляет повторы, сохраняя порядок. |
| `Range(from, to int)` | Создаёт включительный диапазон портов. |
| `Combine(sets ...PortSet)` | Объединяет наборы без повторов, сохраняя порядок первого появления. |
| `(*Scanner).Scan(ctx, hosts, ports)` | Запускает сканирование и возвращает канал `Result`. |

`Result` содержит исходную цель (`Host`), адрес (`IP`), порт, состояние, длительность и исходную ошибку (`Err`). При ошибке DNS `IP == nil`; длительность отражает время DNS-разрешения.

| Состояние | Значение |
|---|---|
| `open` | TCP-соединение установлено |
| `closed` | Получен отказ в соединении |
| `timeout` | Истёк таймаут попытки |
| `unreachable` | Сеть или узел недоступны |
| `canceled` | Отменён контекст сканирования |
| `error` | Другая ошибка, включая ошибку DNS |

Ошибки сохраняют исходную причину и поддерживают `errors.Is` / `errors.As`.

## Цели и отмена

Внешние пробелы в целях обрезаются. Допустимы IP-литералы и ASCII DNS-имена с необязательной завершающей точкой. Дубликаты целей удаляются; DNS-имена сравниваются без учёта регистра и завершающей точки. Каждое уникальное имя разрешается один раз, сканируются все уникальные найденные IP-адреса. Порядок результатов не гарантирован.

Передавайте контекст с дедлайном или отменой. При отмене новые задания не запускаются, поэтому поток может быть неполным. Читайте канал до закрытия; если чтение прекращается раньше, отмените контекст, чтобы разблокировать отправку результатов.
